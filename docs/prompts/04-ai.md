# AI Orchestration Prompt Blueprint

When generating AI integration code for Data Insight, adhere to these strict rules:

## 1. Multi-Model Strategy
Do not blindly use GPT-4 for everything. Route tasks specifically based on the `README.md` guidelines:
- **Claude 3.5 Sonnet**: For data reasoning, Python/Pandas code generation, complex logic, and Excel workbook planning.
- **GPT-4o**: For report writing, executive summaries, and natural language text generation.
- **GPT-4o-mini**: For fast chat routing and quick Q&A.
- **text-embedding-3-large**: For semantic search.

## 2. API & Secrets Management
- Never expose OpenAI or Anthropic API keys to the frontend.
- All AI calls MUST originate from the FastAPI backend (Service Layer).

## 3. Asynchronous AI
- AI calls over a few seconds must be handled via Celery.
- Use async clients (`AsyncOpenAI`, `AsyncAnthropic`) to prevent blocking the FastAPI event loop for shorter calls.

## 4. MCP Server Integration
- Use the Model Context Protocol (MCP) to allow AI models to access the database or file storage securely.
- Ensure strict permission boundaries are maintained (Tenant A's AI agent cannot read Tenant B's data via MCP).

## 5. Token Management & Billing
- Every AI call must track the `prompt_tokens` and `completion_tokens` used.
- Log this usage to the `ai_token_usage` table tied to the `tenant_id` to enforce billing limits.
